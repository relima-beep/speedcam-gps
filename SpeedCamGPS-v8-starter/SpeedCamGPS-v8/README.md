# SpeedCam GPS v8 — starter project
This is a **new minimal Android source project**, not the full historical v7/v8 codebase. It has back-camera recording with optional microphone and a GPS speed readout in preview. The speed is NOT burned into video. Dual camera, antishake, effect studio, challenges, streaming and social integration are NOT implemented in this starter archive. No successful build or device test has been verified.

## Build APK
Upload the **contents** of this folder (including hidden `.github`) to the root of your GitHub repo. Open Actions > Build SpeedCam GPS APK > Run workflow. When successful, download the debug APK artifact. You can also open the folder in Android Studio (JDK 17, Android SDK 35). Do not upload the zip as a single repository file.
